> Java程序员转型AI应用开发，先用熟悉的技术栈快速上手

## 环境准备

- JDK 17+
- Maven 3.8+
- iFlow API Key（免费获取：https://iflow.cn）

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/你的用户名/java_to_ai.git
cd java_to_ai/S01E01

# 配置 API Key（复制 .env.example 为 .env，填入密钥）
cp .env.example .env
# 编辑 .env 文件，填入 IFLOW_API_KEY=你的密钥

# 运行
mvn spring-boot:run

# 测试
curl "http://localhost:8080/chat?message=你好"
```
